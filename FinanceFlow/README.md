# FinanceFlow

Aplicativo web de controle financeiro pessoal em português brasileiro, com frontend em React + TypeScript e backend planejado em Supabase.

## Funcionalidades implementadas nesta entrega

- Fluxo completo de autenticação (cadastro, login e recuperação de senha).
- Painel principal com cards, gráficos e listas.
- Estrutura de navegação e páginas para todos os módulos requisitados.
- Esquema SQL do Supabase com políticas RLS por usuário.
- Tipagem de domínio para transações, cartões, metas, investimentos e relatórios.

## Como executar

```bash
npm install
npm run dev
```

> Caso o ambiente esteja sem acesso ao NPM Registry, mantenha este código como base e execute localmente.
